The illustrations are schematic: a rounded housing, the scroll wheel, the lower
button and three channel LEDs. They exist to make the setup wizard
understandable, not to depict a product accurately.

### Technical notes

- Viewbox `0 0 200 330`, so they scale to any size without loss.
- The LEDs carry the ids `led-1`, `led-2` and `led-3`. The active channel is
  shown by setting the CSS class `mode-1`, `mode-2` or `mode-3` on the root
  `<svg>` element.
- They are served by the integration under `/bilresa_remote/images/` and are
  reachable without authentication. That is intentional and required: the config
  flow dialog renders them before a session token is available to the markdown
  renderer. They contain no user data.

## No product photography

This repository deliberately contains **no IKEA product photos**.

Product photographs are protected works. IKEA's terms of use permit private use
only; publishing them in a public repository would be making them publicly
available, and shipping them under this repository's MIT license would be a
false statement about who holds the rights to them. Original drawings avoid both
problems and are, for a configuration dialog, more useful anyway.

If you contribute a photograph, it must be one you took yourself, and you must
state the license you are releasing it under.
